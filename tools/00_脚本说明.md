# 🧰 工具说明

## 📦 第三方源码与发布准备

`26NOV23_v01_restore_hdf_filters.py` 按 `third_party/hdf_filters/sources.json` 的固定URL和SHA256恢复开发依赖；默认输入/输出为本源树，也可用`--root`指定独立源码树。匹配文件复用，不同文件拒绝覆盖，下载后验证再写入，不执行下载代码。网络仅使用环境代理。

`public-source-excludes.txt` 定义公开快照应排除的第三方代码路径，`package-windows.ps1`在创建源码ZIP前检查指定公开引用，含排除文件则拒绝。缺省`SourceRef=github-main`；本地开发依赖保留。打包验证GRIB运行DLL哈希并包含嵌入定义/样本、许可、帮助；已有输出目录或ZIP拒绝覆盖，指定新`OutputDirectory`即可保留旧包。

## 🎬 README 实机演示录制

`26NOV21_v01_capture_demo.ps1` 从只读环境变量`HDFSTUDIO_DEMO_SAMPLE`打开预报（可选`HDFSTUDIO_DEMO_VARIABLE`，缺省`TMP_2maboveground`），选择cmocean Thermal、打开跟随源图的二维纹理熵、平铺并真实点击Play。截取20帧，使用系统WPF离线编码循环GIF，无新增依赖。输出`docs/demo-analysis.gif`与`docs/screenshot-main.png`，原始帧及源哈希/层索引记录在`logs/S4-TextureEntropy/demo-时间/`。脚本仅操作GUI与导出文档媒体，禁止与其他鼠标验收并行。

`26NOV21_v01_finalize_demo.py` 在录制后执行，按GIF块结构修正WPF编码器遗漏的650毫秒帧延迟，断言20帧/13秒/永久循环并输出大小与SHA256；只读写`docs/demo-analysis.gif`，不依赖图像库。两脚本依次运行构成完整文档媒体流程。

## ▶️ 绿色播放位图

`26NOV21_v01_playback_icons.py` 用Python标准库离线生成透明32×32 RGBA位图，4倍超采样平滑边缘；输入为脚本内固定图形与颜色，输出 `resources/images/play_green.png`、`pause_green.png`，可直接运行，无第三方依赖。控制台和 `logs/S4-Playback/icons/generator.log` 同时记录含时间戳日志。Qt通过 `resources/hdf_explorer.qrc` 编入程序，不依赖运行时外部图片。

## 🔍 图像缩放验收

`../tests/run-zoom-regression.ps1` 复用 Stage 4 双配置编译、完整 QtTest/CTest，随后 Debug/Release 各连续跑 5 次完整 QtTest，失败立即停止并记录截图、Qt 插件日志、进程和部署清单。输出为 `logs/S4-UI-Zoom/`，汇总 `cycle-results.json` 包括配置、循环号、退出码与耗时；可用 `-Cycles` 显式调整次数，默认 5。

`../tests/desktop_zoom.ps1` 用真实桌面鼠标验证放大/缩小、翻转后 5 次往返和只读样本不变，截图中测量栅格彩色区域的宽高，分别断言放大约 1.25 倍、缩小恢复。输入为环境变量 `HDFSTUDIO_ZOOM_SAMPLE`、`HDFSTUDIO_ZOOM_VARIABLE`（默认 PRECT），输出同一日志目录的截图和 `desktop-{results,geometry}-{Debug,Release}.json`。默认 Release，`-Configuration Debug` 可测试 Debug。两脚本复用已部署 Qt，不安装额外依赖。

## 🎨 色表资源

`26NOV21_v01_export_colormaps.py` 从锁定的 `cmap==0.8.0` 原始颜色节点和 NCL 提交生成资源。首次使用 `--fetch` 下载 5 个官方 RGB 文件、目录说明和许可；缺省运行可离线重建，`--check` 逐字节验证。

输入为 Python 环境中的 cmap 包和 `resources/colormaps/source/`；输出为 `resources/colormaps/palettes/*.json`（RGBA N×4 + positions N）、清单、黄金值、Qt qrc，以及 `licenses/colormaps/`。日志写入 `logs/S4-UI-ColorMap/resource-build.log`，同时输出到控制台，均含时间戳。普通程序运行不需要此 Python 环境。

```powershell
python -m venv --system-site-packages build/colormap-env
build/colormap-env/Scripts/python -m pip install cmap==0.8.0
build/colormap-env/Scripts/python tools/26NOV21_v01_export_colormaps.py --fetch
build/colormap-env/Scripts/python tools/26NOV21_v01_export_colormaps.py --check
```

🔎 NCL 顶层 Apache-2.0 与文件内 MeteoSwiss 贡献署名一并保留；cmap 的生成工具许可不覆盖各源数据的 CC0/MIT 许可。资源清单含版本、输入/输出 SHA256，不从配色名称推断变量单位或气象等级。
