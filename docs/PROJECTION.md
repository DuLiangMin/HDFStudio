# 🌍 投影显示与参考海岸线

标量Image顶部有独立的浅蓝色 **Map projection** 单行栏：标签、下拉选择、**Options…** 和状态始终在同一行。直接选择经纬度平面、北极、南极、东亚Lambert或Mercator即重绘并保存，无需打开选项或点击OK；首次选择自动验证坐标。进度、错误和配置失败仍在该行，长文字省略，悬停可看全文。选择 **Source grid** 立即返回原格点图。

旁边的 **Options…** 打开详细参数和海岸线设置。投影、参数与岸线改动立即反映到图像，重绘不等待OK。窗口保留 **OK / Cancel**：OK仅确认详细选项并关闭，Cancel、Esc和右上角关闭撤销本次预览，恢复打开前的模式、视口与岸线样式；Enter对应OK。非法参数显示原因并禁用OK，修正后恢复。

## 💾 自动记住选择

已确认的模式、中心经度、标准纬线、显示范围及岸线开关/颜色/线宽保存在 **HDFStudio.exe所在目录的`HDFStudio.ini`**，`[MapProjection]`组，格式版本1。主栏选择成功即保存，详细设置只有OK写入，预览与取消不写入；下次打开图像自动恢复，无需再次选择。目录不可写时明确提示，详细窗口保留以便重试或取消；损坏/不支持的配置回退源图并显示原因。

配置只保存显示偏好，不保存业务路径、数据值或源球体/椭球。每个源文件重新验证自己的坐标与模型；无法采用已保存模式时保留源图和配置，显示原因。缩放/拖动是当前图像的临时视口，默认只恢复保存的地理显示范围。

## 🧭 源坐标准入

接收末两维明确为纬度、经度的NetCDF一维坐标，以及经ecCodes读取并验证可分离的GRIB `regular_ll`、完整矩形高斯网格 `regular_gg`。高斯纬度保留实际非等距中心，最近邻查找不按等距纬度推算；ecCodes明确验证`global=1`时保留全球经向周期，避免编码端点舍入导致0°接缝留白。NetCDF坐标读取由同目录`hdf_cli.exe`隔离进程执行。`reduced_gg`、二维/旋转坐标、源投影网格、普通HDF矩阵不能仅按shape当作地表地图。

经纬轴有效但没有声明球体/椭球时，五种显示仍可选择。极射、Lambert和Mercator在显示层使用`a=b=1`的单位球面，只生成归一化图形和角度探针，画布明确标记 **Unit-sphere display only / source Earth model unknown / distances unavailable**。这不是对源球体的推断，不提供物理距离或面积；不把单位球写入源模型、INI或科学输出。已声明有效模型仍使用该模型；显式非法/冲突模型、坐标无效仍拒绝。所有模式均不执行datum/历元转换；非Greenwich参考子午线需另外适配，不默认套WGS84。

## 🖱️ 视口与数值

Fit恢复所选地理范围；Zoom及滚轮缩放，拖动地图平移。x/y使用相同投影单位/像素（明确模型时为米，未知模型为归一化单位）或度/像素。按画布物理像素中心逆投影，再在可分离源轴上最近邻取值；鼠标提示报告同一画布像素对应的经纬度、源行列、源格点坐标和值/Mask/缺测状态。

经纬度标注与图上说明采用无矩形底框、无描边的实心文字，按背景明暗选择浅色或深色；相邻标签自动避让。

无有效bounds的非周期轴只覆盖首末中心；未覆盖区域留白，不向边缘钳位。源周期端点的值与Mask必须一致。地图期间Flip禁用；**Profile保持可用，点击自动返回Source grid再按原格点选线、拖点与显示曲线**，并取消尚未完成的投影恢复请求。切回地图时退出选点模式但保留控制点，下次点击Profile可继续使用。原统计、比较、CSV、颜色范围和源格点PNG使用原平面；投影显示不创建科学重网格。新增地图PNG导出后置。

## 🎞️ 投影播放

点击Play后，下一层读取和投影期间保留上一张完整地图及其色标，状态提示previous image；新投影就绪后一起切换，避免逐帧清屏闪烁。计算慢于Frame interval时等待当前地图完成再前进，不跳过尚未完成的投影。等待期间旧地图探针不可用；实际读取/投影失败、源变更或越界仍清空并显示原因。Pause停止前进，当前已请求帧可完成。

## 🌊 本地离线海岸线

默认开启Basemap v2.0.0 / GSHHG 2.3.6低精度`l`参考岸线，仅level 1/5且面积>1000 km²。设置可调整开关、颜色及逻辑像素线宽。岸线只作角度对齐的定位参考，不用于海陆Mask、精密配准或科学计算。

原始数据、规范化折线、manifest与公开转换器在`resources/coastlines/`；GPL/LGPL及配套MIT说明在`licenses/coastlines/`。转换保持真实坐标，删除可追溯的日期线和南极人工封口。构建复制到程序相对目录，运行无需Python或网络。资源缺失、坏hash或超限只使参考岸线不可用并显示原因。

## 📂 构建与依赖

PROJ通过`PROJ_DIR`指向独立CMake包；本机使用`ext/vcpkg/installed/x64-windows/share/proj`，不切换原工程toolchain。精确版本、vcpkg baseline及DLL/数据库hash记录于`resources/proj/dependency-lock.json`。随程序部署匹配DLL、`resources/proj/proj.db`和许可，context显式设置资源目录且关闭网络。显式同模型数学投影与CRS数据库查询分别诊断。

实现与验收入口见[ADR-0004](adr/0004-map-projection-display.md)及`tests/projection_test.cpp`。程序产物为`build/output/{Release,Debug}/`，定向验证与桌面证据保存在开发日志`logs/PROJ-001/`。
