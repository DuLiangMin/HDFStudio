# 🧪 回归脚本说明

## 📂 输入与输出

产品源码在 `src/`，构建在 `build/output/{Debug,Release}/`；业务文件通过 `HDFSTUDIO_*_SAMPLE` 或 `HDFSTUDIO_SAMPLE_ROOT` 传入，保持只读。每轮导出、截图与日志写入 `logs/`，不进入源码包。

| 分组 | 脚本 | 用途 |
|---|---|---|
| ▶️ 播放与按钮联动 | `26NOV21_v01_playback_checks.py` | navigation先验收当前Target时主工具栏推进Anchor；playback验收单图/多图/残差/暂停/末层/关闭；full双配置完整QtTest/CTest，--clean可清理重编译；输入build/vs2022与只读样本环境变量，输出logs/S4-Playback独立阶段目录 |
| 🖱️ 放映桌面验收 | `26NOV21_v01_playback_desktop.ps1` | 环境变量HDFSTUDIO_FORECAST_ANCHOR/TARGET提供只读预报；真实鼠标点击单图Play/Pause、Target激活时Next/Previous和双图联合播放，检查绿色位图/比较入口/残差/指标/暂停/越界恢复/About/源哈希/正常退出；-Executable与-RunLabel可指定便携版，输出logs/S4-Playback/desktop-标签-时间戳 |
| 🔬 放映后指标对账 | `26NOV21_v01_playback_reconcile.py` | 读取双配置最新完整通过的desktop记录与暂停指标，用只读HDFSTUDIO_FORECAST_ANCHOR/TARGET及netCDF4/NumPy复核当前配对的r/RMSE/MAE/Bias、计数、单位和坐标时间；输出logs/S4-Playback/reconcile-时间戳 |
| 🧪 本轮数值 | `26NOV21_v01_full_regression.py` | seed=20261121 分层随机抽取 no_stand_nc，CSV 全值、PNG 全像素、直方图；默认 Release，`--config Debug` 可切配置；输出本轮 numeric/final/配置 |
| 🔬 分阶段分析 | `26NOV21_v01_metrics_checks.py` | `--stage entropy` 先验收熵，再 `--stage pair` 验收双图；双配置构建、解析夹具、CLI退出码和NumPy对账，输入真实文件经环境变量，输出独立时间戳目录 `logs/S4-Metrics-Sync/` |
| 🔁 分析最终回归 | `26NOV21_v01_metrics_final.py` | 双配置clean构建、完整QtTest/XML/CTest、时序各3个独立进程、二进制/源码与只读样本哈希；输出本轮 `final-<timestamp>`，不复用历史PASS |
| 🖱️ 分析桌面 | `26NOV21_v01_metrics_desktop.ps1` | 真鼠标打开双图/分析Dock、滑块/lag/残差/越界恢复/复制/CSV/正常退出；输入HDFSTUDIO_ZOOM_SAMPLE，默认PRECT；失败自动截图/控件/进程/Qt日志 |
| 🌡️ 真实预报分析 | `26NOV21_v01_forecast_metrics.py` | 输入HDFSTUDIO_FORECAST_ANCHOR/TARGET，变量默认TMP_2maboveground；先核查经纬度/时间坐标，再按共同有效时刻/同索引/+2 lag比较，双配置CLI与NumPy逐指标对账及源SHA256保持 |
| 🖼️ 预报残差对账 | `26NOV21_v01_forecast_residual.py` | 输入相同预报环境变量与HDFSTUDIO_FORECAST_RESULT_DIR；读取QtTest导出的CSV/PNG，独立NumPy逐值/逐RGB像素核对3组同有效时刻残差，两配置共6组 |
| 📋 分析验收矩阵 | `26NOV21_v01_metrics_acceptance.md` | P1→P4逐项断言、状态、证据目录与科学边界 |
| 🖱️ 本轮桌面 | `26NOV21_v01_desktop_regression.ps1` | 真鼠标及 UIA，输入 HDFSTUDIO_ZOOM_SAMPLE，默认 PRECT；输出本轮 desktop/配置，-LogDirectory可隔离新轮次，About版本自动读取CMake |
| 🔁 本轮全回归 | `26NOV21_v01_run_regression.py` | 显式配置 classic/packed 样本后，顺序 clean build、完整 QtTest/XML、CTest，时序用例两配置各独立进程 3 次；记录耗时/峰值工作集 |
| 🔬 本轮边界 | `26NOV21_v01_edge_regression.py` | 中文路径/嵌套组、int64/uint64/scalar 精确导出、字符串/复合/VLEN/enum 拒绝、损坏与覆盖保护 |
| 📦 本轮包验证 | `26NOV21_v01_verify_packages.py` | 最终 HEAD 源码逐文件比对、13 色表/7 许可严格哈希、PE 依赖、系统 PATH 下版本/CLI/PNG/GUI退出；版本读取CMake，--packages/--output可指定独立包和证据目录 |
| 🔁 原有双配置 | `run-stage4.ps1` | 构建后执行 QtTest 与 CTest；参数为 logs 下功能目录 |
| 🔎 原有数值 | `reconcile_*.py` | 分别对账 classic、decoded、info、histogram、time；依各脚本头部约定读取 QtTest 派生结果 |
| 🖥️ 原有桌面 | `desktop_*.ps1` | 各专项鼠标/UIA 验收，历史输出目录与本轮报告分开 |
| 🧩 确定性夹具 | `drop_targets_test.cpp` | QtTest 合成数据、GUI 状态和子进程断言；数据放 QTemporaryDir，业务样本只读 |
# 🖼️ 二维纹理熵图补充

`26NOV21_v01_texture_entropy_checks.py`：core→gui→full分阶段双配置构建、QtTest和NumPy逐块/逐像元核对；输入只读业务样本环境变量及确定性临时夹具，输出`logs/S4-TextureEntropy/`和`build/output/{Debug,Release}/`。接口与断言见`26NOV21_v01_texture_entropy_acceptance.md`。

`26NOV21_v01_texture_entropy_desktop.ps1`：真实鼠标从变量右键/主菜单打开二维熵图，翻层、Mask、导出原尺寸PNG/数值CSV、无效恢复、About/正常退出；支持`-Executable/-RunLabel`检查便携程序。只读输入`HDFSTUDIO_FORECAST_ANCHOR`，输出`logs/S4-TextureEntropy/desktop-标签-时间/`，失败自动取证。

`26NOV21_v01_texture_entropy_reconcile.py`：读取上述QtTest或桌面原始PNG/CSV，独立NumPy逐块/逐值及Viridis逐RGB像素核查；`--folder`指定证据目录，默认最近完成的gui/full目录。同目录保存`texture-reconciliation.json`与日志；业务样本哈希保持。

`26NOV21_v01_texture_entropy_regression.py`：clean完整构建后顺序执行Debug/Release真实桌面原图操作23项、二维熵24项、比较分析16项与绿色播放21项；核对实际熵PNG/CSV、比较CSV及播放后r/RMSE/MAE/Bias与NumPy。输入`HDFSTUDIO_ZOOM_SAMPLE`只读PRECT及`HDFSTUDIO_FORECAST_ANCHOR/TARGET`只读预报和可选变量名，输出`logs/S4-TextureEntropy/regression-时间/`；桌面脚本各存原始截图/控件证据，前后校验业务源和程序哈希。
